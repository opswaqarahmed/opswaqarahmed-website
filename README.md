### How results are labelled

- **Sandbox build:** built in a practice account with test or demo data; not paid client work.
- **Tested:** seen in a recorded sample run. Example: on one Full Home test job, 4 matching suppliers were found, Gmail accepted 4 emails, with 0 send failures. Accepted by Gmail does not mean delivered.
- **Estimate:** worked out from a stated assumption. Example: about 17 hours a month saved, assuming eight site visits each week.

## How it is built

A plain static site, generated by `build/build.py` (Python, no dependencies) into `public/`.

- Semantic HTML, one stylesheet (`css/site.css`) and one small script for the mobile menu and the audit form. No frameworks.
- Accessible: skip link, keyboard menu (Escape closes it), visible focus, WCAG AA colour contrast, reduced-motion support.
- Private by design: no cookies, no third-party scripts. Fonts (Manrope, DM Sans) are self-hosted with their OFL licence files. The audit form posts to Formspree.
- Strict security headers in [`public/_headers`](public/_headers).
- SEO basics: unique titles and descriptions, canonical URLs, `sitemap.xml`, `robots.txt`, `llms.txt`, Open Graph tags and structured data that matches the visible page.
- Brand guide, logo and social banners: [`brand/`](brand/).
