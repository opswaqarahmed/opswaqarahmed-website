Quote intake and lead scoring

An 8-node n8n workflow, Elite Lead Scoring, that checks GoHighLevel every 10 minutes, scores new contacts on four details and sends each lead to the right next step.

  • Sandbox build

n8n + GoHighLevel. Last updated 14 November 2026.

  • Build spec8nodes in the n8n scoring workflow
  • Build spec10 minbetween scoring runs
  • Build spec3routing paths: hot, warm, nurture
  • Build spec1 hrdue time for the hot-lead call task

The problem

Renovation companies get estimate requests of very different value. Without scoring, a large kitchen remodel booked for next month waits in the same queue as a small repair someday, and the best leads go cold.

What I built

The Elite Lead Scoring workflow in n8n runs in eight nodes:

How leads are routed

Routing rules
TagWhat happens next
hot-leadA call task is created, due within 1 hour.
warm-leadThe contact joins the nurture sequence.
nurture-leadThe contact is added to the newsletter list.

Why it is built this way

  • A tag (needs-scoring) marks which contacts still need work, so each one is scored once.
  • Scoring rules sit in one place in n8n, so the business can change what counts as a hot lead.
  • The fast path for hot leads is a dated task for a person, not just another automated message.

Before using this for a live business

  • Measure the current process first, so any improvement can be compared with a real baseline.
  • Agree which accounts, data and workflows the business owns. I work through a role-based team invite.
  • Confirm third-party costs, such as GoHighLevel, n8n and messaging plans.
  • Test normal, duplicate, missing-data and failure cases with the team's real rules.
