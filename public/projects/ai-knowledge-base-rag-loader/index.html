AI Knowledge Base & RAG Loader

A one-click n8n workflow that clears the old knowledge and reloads eight structured policy sections into Supabase pgvector, so an AI receptionist answers strictly from verified company facts. Demo build for a sample company (Demo).

The problem

After-hours homeowner inquiries ("Do you handle permits?", "How long does a bathroom take?", "What happens at the site visit?") cause generic chatbots to guess prices or promises. For a remodeling contractor, a guessed price or permit promise becomes a promise the team has to take back. The assistant needs one approved library of verified company facts, and the owner needs a simple way to refresh it when those facts change.

What I built

A four-node linear loader in n8n. One click runs it from start to finish:

Three helper nodes

Helper nodes attached to the Save to Supabase node
NodeSettingWhat it does
Gemini Embeddingsvector(3072)Turns each chunk into a 3,072-dimension embedding.
Default Data LoaderDefaultPasses the knowledge text to the vector store as documents.
Recursive Character Text SplitterChunk size 900, overlap 120Splits the text into overlapping chunks, so an answer is not cut off at a chunk edge.

How it is kept safe and repeatable

  • Eight structured policy sections. The company facts are written as separate sections (services, service area, pricing rules, permits, site visits, warranties, materials, and emergency response), so each answer can be traced to the policy it came from.
  • Row Level Security. Row Level Security is enabled on the Supabase table that holds the knowledge embeddings.
  • 1-click deduplicated refresh. Each run clears the old knowledge before saving, so the library can be reloaded at any time without duplicate rows.
  • GoHighLevel ready. This is the verified RAG knowledge base behind the 24/7 AI Website Receptionist, which passes qualified leads to GoHighLevel through n8n.
